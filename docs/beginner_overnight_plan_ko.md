## 토론에서 수정한 판단

- **Qwen 프로세스 정상 응답은 질문 성공이 아니다.** 빌더의 마지막 완료 상태는
  승인·색인 준비와 독립 앱 실행까지만 센다. 기관·규정 선택, 질문, 답변과 인용 확인은
  Qwen 창에서 이어진다고 표시한다. 서로 다른 세션의 사용 결과를 추측해 완료하지 않는다.
- **Kordoc 설치 기준과 사용자 지정 명령 지원을 구분한다.** 설치 도구는 정확한 4.15.7을
  확인한다. 일반 준비 확인은 설정된 전체 명령을 실행하며, 다른 버전의 동작하는 사용자
  지정 명령을 임의로 금지하지 않는다. 문서별 표 파싱 증거와 사람 승인은 별도 조건이다.
- **검수 화면에는 조항별 다음 버튼이 없다.** 여러 조항 행이 함께 표시되므로, 확인 후
  다른 조항의 실제 위젯을 안내하는지 ID로 검사한다. 같은 안내 제목이 다시 보였다는
  이유만으로 같은 조항이 초기화됐다고 판정하지 않는다.
- **기존 명시적 미검수 승인 정책을 테스트가 바꾸지 않는다.** 안내 조작만으로 승인하지
  않는지 검사하고, 사용자가 경고를 확인한 뒤 명시적으로 승인하는 기존 감사 경로는 유지한다.
- **복구 링크의 주소를 추측하지 않는다.** Qwen에서 돌아갈 빌더 주소를 확실히 알 수 없는
  경우에는 빌더 창의 화면명과 수행할 작업을 안내한다.

## 검증과 공개 범위

실제 브라우저 검사는 공개 합성 DOCX와 실행마다 분리한 임시 저장소를 사용한다.
Qwen 오류·응답 검사는 합성 응답으로 수행하므로 모델 품질을 증명하지 않는다.
기존 65초 영상의 범위와 새 브라우저 회귀 결과는 따로 기록한다.

최종 결과는 [초보자 화면 안내 실행 검증](beginner_ux_verification_ko.md)에 기록한다.
게시 직전 최신 npm 버전을 다시 확인해 최종 설치 기준은 `4.16.0`으로 올렸다.
위 표와 토론의 `4.15.7`은 당시 제안의 기준이며, 변경된 버전은 별도 회귀와 실제
합성 문서 변환을 통과했다. 권한 설정 적용 후 사용자의 계속 진행 요청에 따라
목표 시간 이후에도 최종 검증·문서·게시를 마무리했다.
보호 변경의 기본 브랜치 병합에는 저장소 정책에 따른 Code Owner 검토와
`preprocessing-reviewed` 라벨이 필요하며, 작업 브랜치 게시를 이 검토의 완료로 표시하지 않는다.
