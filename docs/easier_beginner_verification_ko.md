# 쉬운 초보자 안내 보완과 검증

2026년 9월 29일. 처음 보는 사람도 지금 할 일을 이해하도록 버튼, 비교 화면, 도움말,
AI 질문 화면을 다시 검토했다. 어린이 대상 사용성 시험을 진행했다는 뜻은 아니다.

## 바뀐 화면

- 검토는 **원래 문서**와 **저장할 내용** 두 칸으로 넓게 보여 준다. AI의 의견과 저장된
  수정 제안은 바로 아래에서 확인한다. 작은 화면에서도 제목이 해당 내용 앞에 붙는다.
- **잘 모르겠어요 · 확인 방법 보기**는 날짜·금액·표를 비교하는 방법과 문서를 아는 사람에게
  물어봐야 할 때를 설명한다. 도움말을 열어도 판단·확인·승인이 기록되지 않는다.
- **고칠 곳이 있어요**를 선택하면 내용을 고치거나 해결 방법을 적어야 다음으로 갈 수 있다.
  해당 문제가 실제로 없을 때는 **이 문제는 없어요**를 고른다.
- **내용이 맞아요 · 다음**으로 하나씩 확인한 뒤 **승인하고 AI 질문 준비하기**를 누른다.
  자동 승인, 미확인 조항 우회, AI 수정안 자동 반영은 하지 않는다.
- Qwen 질문 화면에서는 기관과 규정을 고르고 **AI 연결 확인**을 누른다. 연결이 확인되기 전에는
  질문창과 답변 설정을 표시하지 않는다. 준비 상태 표와 답변 설정은 기본으로 접어 둔다.
- 안내 글자와 안내 버튼 글자를 16px로 키웠다. 이미 검토 화면에서 다시 같은 단계로
  이동하라는 안내와, 승인한 내용을 미확인 경고로 보이게 하던 문구를 수정했다.

## 검사 범위

가상 장비 대여규정 DOCX를 새 기관에 올려 실제 Chromium에서 안내된 화면을 따라 진행했다.
실제 문서 파싱, 승인 기록, 검색 등록과 로컬 Qwen을 사용했다. 문서에는 다섯 조문, 부칙과
3행 2열 표가 있으며 총 8개 내용으로 나뉜다. 실제 기관 문서와 외부 AI 키는 사용하지 않았다.

1. 기관 생성 → 파일 업로드 → 문서 정보 확인 → 전처리 → 검토 화면 이동.
2. 도움말을 펼쳐도 다음 확인과 최종 승인 버튼이 생기지 않음을 확인.
3. 8개 내용을 원문과 비교하고 주의 항목을 판단한 뒤 각각 명시적으로 확인.
4. 확인한 조항을 다시 열어 최종 승인이 잠기고, 재확인 뒤 열리는 것을 확인.
5. 마지막 승인 버튼으로 승인·검색 등록 후 독립 Qwen 화면에서 기관·규정 선택.
6. 실제 AI 연결 확인 → 대여 신청 기한 질문 → 답변과 근거 확인.

최종 화면으로 다시 실행한 결과 승인 기록은 1건, 승인된 실제 의미 검색 벡터는 8개,
색인 작업은 완료 상태였다. “장비 대여 신청은 언제까지 해야 하나요?”에 **사용일의
3근무일 전**이라는 답변과 **제2조 대여 신청·원문 1쪽** 근거가 표시됐다. 이 실행의
답변 완료 표시는 7.7초이며 브라우저 오류는 0건이었다. 앞선 검사 스크립트의 20초
대기 한도는 첫 모델 연결을 기다리기에 짧아 시간 초과됐으나 앱의 연결은 완료됐다.
최종 실행에서는 최대 60초까지 실제 완료 상태를 기다려 연결과 답변을 확인했다.

저장된 AI 제안의 아래쪽 표시, 명시적 반영, 반영만으로 원본 저장·승인되지 않는 조건과
‘고칠 곳이 있어요’ 선택 후 해결 전 진행 차단은 별도 AppTest로 검증했다.

관련 화면·안내·문서·질문 회귀 195개와 Chromium 안내 제어기 검사를 통과했다.
전체 자동 검사, 패키지 빌드, 공개 파일 위생 검사의 최종 결과는 병합 PR에 함께 기록한다.
