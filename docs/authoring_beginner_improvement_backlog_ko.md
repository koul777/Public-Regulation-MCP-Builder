# 초보자용 규정 작성 후속 개선 백로그

기준일: 2026-08-30

## 목적

P0는 초보자가 로컬 화면에서 규정 초안을 안전하게 시작하고 export-only 초안 패키지까지
만들 수 있게 하는 최소 기능이다. 다음 단계에서는 "안전하다"를 넘어서 "헷갈리지 않고
빠르게 끝낼 수 있다"를 목표로 삼아야 한다.

## 우선순위 P0.1 — 바로 착수할 개선

### 1. 시작 화면 질문 축소

- 문제: 첫 화면에서 기관, 작성 방식, 템플릿을 한 번에 묻기 때문에 초보자는 어디부터
  눌러야 하는지 잠시 멈춘다.
- 개선:
  - 첫 단계는 `무엇을 만들까요?` 한 질문으로 시작한다.
  - 답변에 따라 다음 단계에서 작성 방식과 템플릿을 좁혀 보여준다.
- 성공 기준:
  - 첫 클릭까지 걸리는 시간이 파일럿 중앙값 기준 30% 이상 감소
  - `어디서 시작하나요?` 질문 빈도 감소

### 2. 필수 입력 우선 모드

- 문제: 초보자는 모든 칸을 한 번에 채우려다 중간에 포기하기 쉽다.
- 개선:
  - `지금 꼭 필요한 항목만 보기` 토글을 둔다.
  - 규정명, 목적, 적용 범위, 근거, 담당부서만 우선 노출하고 나머지는 접어 둔다.
- 성공 기준:
  - 초안 시작 후 5분 이내 첫 저장 비율 상승
  - 빈 초안 이탈률 감소

### 3. 검토 요청 전 자동 누락 요약

- 문제: 작성 검사를 돌려도 무엇부터 고쳐야 하는지 초보자가 바로 이해하지 못할 수 있다.
- 개선:
  - `지금 막는 핵심 3가지` 요약 상자를 오류 목록 위에 둔다.
  - 조문 번호, 누락 항목, 바로 고칠 위치를 함께 표시한다.
- 성공 기준:
  - 첫 검사 후 두 번째 검사까지 걸리는 시간 단축
  - 같은 오류의 반복 발생률 감소

### 4. 개정 방식 설명 카드

- 문제: `신규 제정`, `일부 개정`, `전부 개정` 구분이 초보자에게 어렵다.
- 개선:
  - 각 선택지 아래에 한 줄 예시를 넣는다.
  - 선택 전에 3개 예시 카드만 보여주고, 세부 도움말은 접어 둔다.
- 성공 기준:
  - 잘못된 작성 방식 선택 후 되돌리기 비율 감소

## 우선순위 P1 — 파일럿 통과 뒤 확장

### 5. 템플릿 추천 질문

- 문제: 어떤 템플릿을 골라야 할지 판단이 어렵다.
- 개선:
  - `회의 운영`, `위원회`, `업무 절차`, `기타` 같은 쉬운 질문 2~3개로 후보를 좁힌다.
  - 추천은 하되 자동 확정은 하지 않는다.
- 성공 기준:
  - 템플릿 재선택 횟수 감소

### 6. 쉬운말 작성 예시 슬롯

- 문제: 조문 본문을 어떤 문체로 써야 하는지 감이 부족하다.
- 개선:
  - 각 섹션마다 `이런 식으로 씁니다` 예시 1개를 회색 안내문으로 제공한다.
  - 예시는 저장되지 않고 사용자가 직접 지워야 입력란으로 복사되지 않게 한다.
- 성공 기준:
  - 초안 길이 편차 감소
  - 첫 저장 전 머무는 시간 감소

### 7. 초안 비교 보기

- 문제: 수정 요청 뒤 무엇이 달라졌는지 스스로 확인하기 어렵다.
- 개선:
  - 마지막 동결본 또는 직전 저장본과 현재 초안을 나란히 비교한다.
  - 바뀐 조문만 접어서 보여준다.
- 성공 기준:
  - 수정 요청 후 재검토 완료율 상승

## 우선순위 P2 — 운영 증거 확보 뒤 검토

### 8. AI 보조 문안 제안

- 전제:
  - P0와 분리된 통제 모델
  - provenance 기록
  - 채택/미채택 이벤트 분리
  - 공식 승인 경로 자동 연결 금지
- 목적:
  - 빈칸 채우기 힌트 제공
  - 초보자 문장 시작 부담 완화
- 보류 이유:
  - 안전성과 책임 경계가 P0보다 훨씬 커진다.

### 9. 기관별 템플릿 꾸러미

- 목적: 자주 쓰는 규정 유형별 시작 속도 향상
- 조건:
  - 공개 가능한 일반 템플릿만 사용
  - 기관 고유 민감 정보는 포함 금지

## 측정 체계

| 지표 | P0 기준 | 후속 목표 |
|---|---:|---:|
| 초안 시작 성공률 | 90% 이상 | 95% 이상 |
| 첫 저장 도달률 | 측정 예정 | 85% 이상 |
| 검토 요청 완료율 | 80% 이상 | 90% 이상 |
| 공식 승인 오인 | 0건 | 0건 유지 |
| 첫 오류 수정 완료 시간 | 측정 예정 | 30% 단축 |

## 권장 실행 순서

1. 초보자 파일럿으로 실제 막힘 지점을 수집한다.
2. P0.1 항목 1~4를 문구·레이아웃 중심으로 먼저 반영한다.
3. 같은 파일럿 과업을 다시 돌려 개선 전후 지표를 비교한다.
4. 그 뒤에만 P1 확장을 검토한다.
5. 운영 증거가 모이기 전까지 P2는 설계 메모 수준에서만 다룬다.
