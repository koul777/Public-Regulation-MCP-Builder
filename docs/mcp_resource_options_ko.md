# MCP 시작 시 메모리 사용 선택

기존 실행 기본값과 `--no-warm-cache`의 동작은 유지됩니다. `--no-warm-cache`는 승인 벡터·승인 스냅샷·BM25의 시작 시 준비를 건너뛰며, 기본적으로 별도의 백그라운드 토크나이저 준비는 계속 수행합니다.

백그라운드 토크나이저 준비도 생략하려면 두 옵션을 함께 지정합니다.

```powershell
python scripts/run_regulation_mcp.py --transport stdio --no-warm-cache --no-background-tokenizer-warmup
```

`--no-background-tokenizer-warmup`은 `--no-warm-cache`와 함께 사용해야 합니다. 이 옵션은 시작 시 선택적인 준비 작업만 생략합니다. 토크나이저가 필요한 첫 질의에서는 기존 모델이 그대로 초기화될 수 있으므로 메모리 사용과 첫 응답 시간이 증가할 수 있습니다. 절감 효과는 질의와 실행 환경에 따라 달라집니다.

토크나이저 준비 상태에 따라 초기 질의 결과가 달라질 수도 있습니다. 실제로 사용할 질의와 권한 범위에서 확인한 뒤 선택하세요.

기존 기관·테넌트·승인·접근 권한·HTTP 인증 설정은 그대로 지정해야 합니다. 이 옵션은 검색·토큰화 알고리즘이나 보안 검증을 우회하거나 변경하지 않습니다.
