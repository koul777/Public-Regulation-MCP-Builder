# 초보자용 규정 작성 파일럿 진행 스크립트

기준일: 2026-08-30

## 목적

초보자 1인당 무개입 과업 30분, 사전 안내와 사후 질문을 포함해 전체 45분 내외로
같은 방식의 관찰을 수행하고, 화면 문구와 흐름 때문에 어디에서 멈추는지 비교
가능하게 기록한다.

## 진행 전 준비

- 테스트용 로컬 환경을 켠다.
- 실재 기관 대신 사용성 검증 계획의 가상 기관 프로필과 가상 입력만 준비한다.
- 전체 참여자 중 적어도 한 명은 키보드만 사용하고, 적어도 한 명은 브라우저 200%
  확대와 좁은 창에서 같은 과업을 수행하도록 배정한다.
- 참가자에게 이 기능이 `공식 승인 아님`인 연습용 초안 작성 화면임을 먼저 설명하지
  말고, 화면만 보고 스스로 이해하는지 본다.
- 관찰자는 정답을 먼저 알려주지 않는다.

## 시작 멘트

다음 한 문장만 읽어 준다.

> “새 규정을 처음 만드는 사람이라고 생각하고, 화면을 보면서 초안을 작성해 주세요.
> 막히면 무엇이 헷갈리는지 소리 내어 말해 주세요.”

## 공통 과업

1. 새 규정 작성 화면으로 들어간다.
2. [사용성 검증 계획의 가상 시나리오](authoring_beginner_usability_test_plan_ko.md)를
   보고 신규 제정과 위원회 운영 템플릿을 선택한다.
3. 제공된 규정명, 목적, 적용 범위, 근거, 담당부서와 시행 예정일을 입력한다.
4. 진행자가 지정한 필수 조문 하나를 첫 검사 전까지 비워 두고, 다른 한 조문에는
   `이 규정 제99조`를 참조하도록 입력한다.
5. 작성 검사를 실행하고 빈 필수 조문과 잘못된 내부 참조를 안내만 보고 고친다.
6. 작성자 확인 목록을 완료하고 내용 확인을 요청한다.
7. `연습용 자체 확인`의 의미를 자기 말로 설명한 뒤 사유를 입력하고 내용을 동결한다.
8. Markdown 초안 패키지를 내려받고, 이 파일이 기관 결재·법적 검토·RAG 승인·색인을
   뜻하는지 질문에 답한다.
9. 같은 가상 초안을 두 창에서 열어 사용성 검증 계획의 충돌 복구 과업을 수행한다.

## 관찰 포인트

### 시작 단계

- 첫 클릭까지 몇 초 걸렸는가
- 참가자가 `어디서 시작해야 하는지 모르겠다`고 말했는가
- `신규/일부/전부 개정` 의미를 바로 이해했는가

### 작성 단계

- 필수 입력을 스스로 찾았는가
- 조문 입력 위치를 자연스럽게 찾았는가
- 안내 문구를 읽고 행동을 바꿨는가

### 검토 단계

- `작성 검사` 결과에서 무엇을 먼저 고칠지 이해했는가
- 오류 위치로 다시 이동하는 데 헤맸는가

### 경계 이해

- 이 기능이 공식 승인 흐름이 아니라는 점을 스스로 인식했는가
- 다운로드 파일이 바로 기존 RAG/MCP로 가는 것으로 오해했는가

## 중단 기준

- 참가자 1명이라도 민감 정보나 실제 기관 결재로 오인하면 즉시 파일럿 문구를 재검토한다.
- 2명 이상이 같은 단계에서 30초 이상 멈추면 해당 단계는 다음 배치 전에 문구나 배치를 수정한다.
- 참가자 2명 이상이 다운로드 결과를 공식 산출물로 이해하면 배포 판정을 보류한다.

## 파일럿 직후 정리

1. 참가자별 기록을 한 표로 합친다.
2. 같은 막힘 지점을 3개 이하 상위 이슈로 묶는다.
3. 문구 수정으로 해결 가능한지, 상태 흐름 변경이 필요한지 분류한다.
4. 다음 배치 전에 수정 여부와 근거를 남긴다.
