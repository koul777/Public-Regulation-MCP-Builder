# 공공기관 규정 로컬 AI 플랫폼 구현 계획

## 1. 목표

이 저장소를 다음 제품 흐름으로 발전시킨다.

```text
규정 등록 → 구조화/품질검사 → 사람 승인 → 승인된 최신본 색인
                                      ↓
                         로컬 규정 질의응답 + 근거 조문
                                      ↓
                         필요 시 MCP로 외부 AI 연결
```

핵심은 MCP 기능을 버리는 것이 아니라, 로컬 QA를 기본 사용자 경험으로 만들고 MCP를 동일한 RAG 엔진의 선택적 연결 계층으로 두는 것이다.

## 2. 고정할 원칙

- 새 프로젝트 폴더를 만들지 않고 현재 저장소에서 단계적으로 발전시킨다.
- 승인되지 않은 청크는 검색·로컬 답변·MCP 모두에 노출하지 않는다.
- 로컬 LLM은 답변 표현을 담당하고, 검색 결과와 인용은 시스템이 결정한다.
- 근거가 없으면 추측하지 않고 확인 불가로 답한다.
- 모델 가중치·원문 문서·운영 데이터는 Git에 넣지 않는다.
- 1차 로컬 LLM은 Qwen3 8B를 사용한다. Ollama에서는 `qwen3:8b`, llama.cpp에서는 Qwen3 8B GGUF 경로를 설정한다.
- 외부 API 없이도 전처리·검색·추출식 답변이 동작해야 한다.
- 기존 MCP 계약과 tenant/기관/최신본/보안등급 정책을 유지한다.

## 3. 단계별 실행 계획

### 단계 0 — 기준선 고정

목표: 현재 기능을 안전하게 보존한다.

작업:

- 현재 테스트와 공개 릴리스 위생 검사를 기준선으로 기록한다.
- `app/rag/local_llm.py`의 기존 Ollama·llama.cpp·OpenAI-compatible 계약을 호환 facade로 유지한다.
- 로컬 QA 전환 중에도 `extractive` backend와 MCP smoke가 계속 통과하도록 보호 테스트를 추가한다.
- 현재 작업 트리의 사용자 변경 사항은 건드리지 않는다.

완료 기준:

- 전체 unittest 통과
- `/api/rag/chat`의 추출식 답변과 기존 MCP `search`/`fetch` 동작 유지
- 승인·tenant 격리 테스트 통과

### 단계 1 — 답변 파이프라인 분리

목표: 검색, context 구성, LLM 호출, 인용 생성을 분리한다.

권장 모듈:

```text
app/rag/
  answer_service.py       # 질의응답 전체 orchestration
  answer_policy.py        # 근거 부족·거부·출력 제한
  citation_builder.py     # 시스템이 검증한 citation 생성
  backends/
    base.py
    extractive.py
    ollama.py
    llama_cpp.py
```

작업:

- 기존 `local_llm.py`는 한동안 외부 호출 호환 facade로 둔다.
- `routes_rag.py`가 backend별 세부 구현을 직접 알지 않도록 한다.
- 답변 내부 모델을 `answer`, `citations`, `evidence_ids`, `answer_mode`, `abstained` 형태로 정리한다.
- LLM이 생성한 citation은 신뢰하지 않고 검색 결과에서 다시 만든다.

완료 기준:

- backend를 바꿔도 검색·보안·인용 정책이 동일하다.
- 모델 오류 시 추출식 fallback 또는 명확한 503 상태가 나온다.
- 새 서비스 단위 테스트가 추가된다.

### 단계 2 — 로컬 모델 운영 MVP

목표: 운영자가 모델을 쉽게 연결하고 상태를 확인한다.

우선순위:

1. Ollama + Qwen3 8B 프로필
2. llama.cpp + Qwen3 8B GGUF 프로필
3. 기존 OpenAI-compatible 로컬 서버에서 Qwen3 8B를 등록한 프로필

작업:

- backend·endpoint·model·timeout·출력 길이를 프로필로 관리한다.
- `local_llm_doctor` 명령 또는 동등한 진단 모듈을 만든다.
- endpoint는 기본적으로 localhost만 허용한다.
- 모델 자동 다운로드는 기본 비활성화한다.
- UI에 연결 상태, 모델명, 응답 시간, 실패 원인, 현재 답변 모드를 표시한다.
- 모델이 없어도 `extractive` 모드로 앱 전체를 사용할 수 있게 한다.

완료 기준:

- 모델 미설치 상태에서 안전한 기본 모드로 실행된다.
- Ollama 연결 후 같은 질의가 로컬 모델 답변으로 전환된다.
- 외부 endpoint 설정은 차단되거나 명시적 운영 설정 없이는 사용할 수 없다.

### 단계 3 — 검색·임베딩 품질 고도화

목표: 자연어 질문의 검색 품질을 높이되 재현성을 유지한다.

작업:

- 현재 `local-hash-embedding-v1`은 deterministic fallback으로 보존한다.
- 의미 기반 로컬 embedding backend를 선택 기능으로 추가한다.
- 모든 벡터에 embedding 모델명·버전·차원을 기록한다.
- embedding 모델이 바뀌면 자동으로 기존 벡터를 섞지 않고 재색인을 요구한다.
- 키워드·구조 locator·vector 검색의 결과를 같은 회귀 질의셋으로 비교한다.
- 조문 번호, 규정명, 별표·별지, 표 질의의 별도 품질 지표를 유지한다.

완료 기준:

- 기존 회귀 질의 결과가 악화되지 않는다.
- 모델별 검색 결과와 색인 버전이 추적된다.
- 의미 기반 모델이 없어도 기존 검색이 동작한다.

### 단계 4 — 근거 기반 답변 품질 게이트

목표: “그럴듯한 답변”이 아니라 검증 가능한 답변을 만든다.

작업:

- 근거 충분성 판정과 답변 거부 정책을 명시한다.
- 답변에 규정명·조문·문서·페이지 등 공개 가능한 citation을 붙인다.
- 답변에 로컬 경로, 내부 ID, 비공개 운영 메모가 섞이지 않도록 필터링한다.
- 질문·검색 후보·선택 근거·모델·답변·citation trace를 남긴다.
- 답변 회귀셋을 추가한다.

필수 평가 항목:

- 승인 데이터만 사용했는가
- 정확한 조문을 인용했는가
- 근거가 부족할 때 거부했는가
- 다른 기관/tenant 문서를 섞지 않았는가
- 모델 장애 시 안전하게 대체했는가

### 단계 5 — Streamlit 운영 화면 전환

목표: 사용자가 MCP를 몰라도 로컬 규정 AI를 사용할 수 있게 한다.

화면 순서:

1. 기관/프로젝트 선택
2. 규정 등록
3. 전처리 결과 확인
4. 검수·승인
5. 색인 상태 확인
6. 로컬 AI 설정·진단
7. 규정 질문과 근거 조문 확인
8. 선택적으로 MCP 생성·연결

작업:

- 첫 화면의 주요 행동을 “MCP 생성”에서 “규정 질문하기”로 바꾼다.
- MCP는 고급/외부 연결 메뉴로 이동한다.
- 답변 옆에 원문 비교, 조문 열기, 근거 부족 사유를 제공한다.
- 초보자 모드와 전문가 모드의 기능 차이를 유지한다.

### 단계 6 — 배포·패키징

목표: 기관 PC 또는 폐쇄망에 반복 설치할 수 있게 한다.

작업:

- 기본 설치와 `local-llm` 선택 의존성을 분리한다.
- 모델 파일은 별도 설치 경로 또는 운영자가 지정한 경로에서 읽는다.
- Windows 실행판에서 모델 미설치·GPU 없음·포트 사용 중 상태를 안내한다.
- 기관 문서와 runtime data가 배포 ZIP·sdist·wheel에 들어가지 않는지 검사한다.
- 로컬 QA smoke, MCP smoke, tenant 격리, 공개 릴리스 위생을 하나의 release gate로 묶는다.

## 6. 1차 출시 판단 기준

다음 조건을 모두 만족할 때 로컬 AI 중심 전환을 1차 완료로 판단한다.

- 승인된 규정만 검색된다.
- 모델 없이도 근거 기반 답변이 나온다.
- Ollama 또는 llama.cpp 연결 시 자연어 답변이 나온다.
- 모든 답변에 시스템이 만든 근거 citation이 붙는다.
- 근거가 없으면 추측하지 않는다.
- 기관·tenant 범위 밖의 데이터가 보이지 않는다.
- 기존 MCP `list`/`search`/`fetch` smoke가 통과한다.
- 문서·모델·runtime data가 공개 배포물에 포함되지 않는다.
